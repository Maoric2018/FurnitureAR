# UI audit — 24 October 2026

Scope: the Furniture AR web app and scanner setup page. All production components and their conditional controls were reviewed. Manual browser walkthroughs used the real App with simulated API responses and a synthetic camera; no GPU requests or user camera access were used.

## Changes

- Overview: removed decorative room image, repeated instructions and the redundant empty recent-layout block.
- Product search/preview: shorter labels and error text, fewer repeated eligibility notices, one close control, compact photo navigation, retained units, measurements, availability and color caveats.
- Layout editor: one 3D/AR entry, room scan in the header, concise guidance, accessible duplicate/remove icons and selected states. Enter/Space selects floor-plan furniture. Opening an unmodeled saved item closes the picker before preview.
- Photo to 3D: one upload entry, concise capture tips, one progress indicator, clearer restored-job state, compact empty mobile stage. Kept the elapsed timer, retry actions, measured-height requirement, download and camera fallback.
- Room scan: concise upload/scan chooser, icon back button, accurate bounds and wall-section labels. Preserved native handoff, existing import, replacement behavior and the installed scanner's old-site-return notice.
- Shared controls: accessible names/tooltips for icon actions; 44px minimum mobile icon targets; retained contextual navigation labels and recovery actions.
